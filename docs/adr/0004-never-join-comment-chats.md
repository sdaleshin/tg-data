# Чаты комментариев читаем без вступления и никогда не вступаем

Чат комментариев индексируется без членства в нём: подписки на канал достаточно, потому что при линковке группы к каналу Telegram принудительно открывает её историю, а публичной супергруппе скрыть историю нельзя вообще. Если группа всё же недоступна, Source помечается неактивным с указанием причины — и на этом всё.

Вступать в такую группу запрещено, и это не осторожность, а защита данных. Если у супергруппы включена настройка «скрыть историю для новых участников», момент вступления навсегда фиксирует для аккаунта нижнюю границу видимости: всё, что было раньше, не станет доступно ни после выключения настройки, ни после выхода и повторного входа. Это подтверждено ответом администрации Telegram на bugs.telegram.org/c/60444. Попытка «на всякий случай вступить, чтобы точно был доступ» способна безвозвратно уничтожить возможность выгрузить историю комментариев.

## Consequences

- Правило «индексируем только чаты, где аккаунт уже состоит» действует для каналов и групп, но для чатов комментариев инвертировано: там членство нежелательно.
- Сущность группы берётся из `channels.getFullChannel(канал).chats` по `linked_chat_id`, а не резолвится отдельно: иначе не будет `access_hash`.
- Диагностика доступа — пробный запрос истории с лимитом 1. `ChannelPrivateError` означает «нет доступа», и это конечный ответ, а не повод что-то предпринимать.
